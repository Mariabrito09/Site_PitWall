Projeto desenvolvido como requisito e objeto de estudo para o curso de **Desenvolvimento de Sistemas** da instituição **SENAI A. Jacob Lafer**. 

Trata-se de uma *landing page* temática e imersiva para o **Grande Prêmio de São Paulo de Fórmula 1**, projetada com foco em semântica, estilização moderna e responsividade.

---

## 🏁 Sobre o Projeto

O site simula uma página oficial para a venda de ingressos e acompanhamento do GP de Interlagos (edição 2026). Ele apresenta informações sobre o evento, destaca pilotos (incluindo o brasileiro Gabriel Bortoleto na Audi), exibe a classificação do campeonato e oferece um formulário detalhado para a reserva de ingressos.

### 🛠️ Tecnologias Utilizadas
- **HTML5**: Estruturação semântica do conteúdo (`<header>`, `<main>`, `<section>`, `<nav>`, etc.).
- **CSS3**: 
  - Utilização de variáveis (Custom Properties) para consistência no design.
  - Layouts modernos utilizando **Flexbox** e **CSS Grid**.
  - Design Responsivo com *Media Queries* (adaptação para tablets e smartphones).
  - Estilização de formulários e tabelas.
- **Tipografia**: Google Fonts (`Titillium Web`, tipografia que remete à velocidade e tecnologia).

---

## ✨ Funcionalidades

- **Seção Hero (Início):** Banner de destaque com layout assimétrico (utilizando `clip-path`) e estatísticas rápidas do circuito.
- **Grid de Pilotos:** Cards dinâmicos e estilizados com as cores temáticas de cada equipe (Ferrari, McLaren, Mercedes e Audi).
- **Tabela de Classificação:** Exibição clara da tabela do campeonato de pilotos.
- **Formulário de Ingressos:** Formulário de reserva contendo diversos tipos de inputs (texto, email, data, número, selects e upload de arquivo de imagem).
- **Navegação Suave:** Âncoras no menu principal que direcionam o usuário fluidamente para as seções do site.

---

## 🚀 Como visualizar o projeto

Para rodar este projeto localmente, não é necessário nenhum servidor ou instalação complexa.

1. Faça o clone deste repositório ou baixe o código-fonte em um arquivo `.zip`.
2. Extraia os arquivos em uma pasta na sua máquina.
3. Certifique-se de que a pasta `img/` contém a imagem utilizada na página inicial (`piloto.jpg`).
4. Clique duas vezes no arquivo `index.html` para abri-lo no seu navegador padrão.
